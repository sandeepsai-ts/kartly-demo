Authentication scenarios

Different kinds of users and login flows, all client-side so they run anywhere. Every scenario has its own form and result area.

Test ideas and selectors
  • Users (password for all: Demo-Only-2026): demo_shopper works; locked_shopper is locked out; slow_shopper takes 3 seconds; error_shopper fails about half of the time; expired_shopper must change the password.
  • MFA step: the one-time code is 123456; three wrong codes lock the form; a resend button is disabled for 10 seconds.
  • Session timeout: a 20 second session shows a countdown, then forces re-login.
  • Captcha-style challenge: answer a simple sum; the question changes on every load.
  • Password reset: validates the email format and always answers the same way, whether or not the account exists.
