Dynamic content and waits

Timing is the biggest source of flaky tests. Each demo changes the page after a delay, on purpose.

Test ideas and selectors
  • Late element: #late-el is added to the DOM after the chosen delay (not just made visible).
  • Hidden then shown: #hidden-el is in the DOM from the start but display:none.
  • Disappearing: #vanish-el is removed after 4 seconds.
  • Random ids: the button id changes on every load; use the data-testid value rand-btn.
  • Stale element: #rerender-btn is replaced with a new node every 2 seconds.
  • Overlay: a spinner covers the page for 2 seconds after Submit and intercepts clicks.
  • Flaky action: choose a failure rate; run it many times.
  • Moving target: the button slides left and right continuously.
