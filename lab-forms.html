Forms and inputs

Native and custom controls, client-side validation, masks and every input state a test has to cope with.

Test ideas and selectors
  • Required, pattern, min/max and cross-field (password match) validation with aria-invalid and .field-error.
  • Disabled and read-only inputs: #f-disabled, #f-readonly.
  • Multi-select, optgroups, datalist, custom ARIA dropdown #combo, hidden checkbox behind a switch.
  • Character counter, number stepper limits, date/time/color/range inputs, phone mask, show/hide password.
  • Submit result is JSON in #form-result; errors list in #form-errors.
