Mouse, keyboard and clipboard

Pointer gestures and keyboard events that simple click-and-type automation does not cover.

Test ideas and selectors
  • Hover menu opens on mouse over or keyboard focus; tooltip appears after hover.
  • Double click counter #dbl-count, right click custom menu #ctx-pad, long press (hold 1 s) #hold-btn.
  • Drag and drop: HTML5 (#dnd-a to #dnd-b) and a pointer-driven draggable box #drag-box.
  • Key logger #key-log records key, code and modifiers; Ctrl/Cmd+K opens a search box.
  • Clipboard: copy a value and paste into a textarea; contenteditable editor with a bold button.
