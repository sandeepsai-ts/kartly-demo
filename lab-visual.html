Visual and media

Images, canvas, SVG and layout edge cases that DOM text assertions cannot see.

Test ideas and selectors
  • Broken image (#img-broken, alt text shown), lazy image far below the fold, inline SVG with clickable shapes.
  • Canvas drawing with the pointer: assert pixels or use visual comparison; #clear-canvas resets it.
  • Infinite CSS animation and a pausable pulse: wait for stability, or pause animations.
  • Carousel auto-advances every 4 s; use the next and previous buttons for determinism.
  • Overlapping element: #covered-btn sits under an overlay (click intercepted).
  • Text edge cases: ellipsis, very long unbroken word, emoji, combining characters, RTL text.
